# 비트겟 → 노션 매매일지

레오(Siwoo)의 선물/레버리지 매매일지를 노션에 기록한다.

- data_source_id: `2e19bad3-6ac4-454f-a142-bcea1866535d`
- 노션 커넥터(`mcp__Notion__*`) 필요. 없으면 연결을 안내한다.

## 원칙

**빈칸으로 두지 않는다.** 모르면 비워두는 게 아니라 "없었다"고 기록한다.
빈칸은 나중에 복구할 수 없고, `손절액`과 `진입 근거`가 비면 R 분석과
셋업별 기대값을 낼 수 없다.

## 순서

**1. 스크린샷에서 읽는다**
심볼 / 방향(롱·숏) / 레버리지 / 진입가 / 청산가 / 손익(USDT).
확실하지 않은 숫자는 추측하지 말고 묻는다.

**2. 없는 값 세 개를 한 메시지에 묻는다**
스크린샷에 보통 증거금·손절액·진입 근거가 없다. 나눠 묻지 말 것 —
귀찮아지면 건너뛰게 된다. `AskUserQuestion`을 쓸 수 있으면 그걸로 묻는다.

> 1. **증거금**: 얼마 넣으셨나요?
> 2. **손절액**: 잃어도 된다고 계획한 금액은? (안 정했으면 "없음")
> 3. **진입 근거**: 아래 중 하나 + 한 줄
>    `지지저항` `되돌림` `돌파` `유동성스윕` `이평` `뉴스` `감`

**3. 답을 규칙대로 기록한다**

- 손절액을 답하면 → 그 숫자.
  "없음"이면 → `0` + `실수 태그`에 **"손절 미설정"** 추가.
  **답을 못 받은 채로 페이지를 만들지 않는다.** 한 번 더 묻는다.
- 진입 근거는 반드시 **`[셋업이름] 설명`** 형식.
  예: `[유동성스윕] 전일 저가 쓸고 반등`, `[감] 근거 없이 진입`
  대괄호가 있어야 셋업별로 묶어 통계를 낼 수 있다. 설명은 생략 가능.
- 손익이 없고 ROI(%)만 있으면 `손익 = 증거금 × ROI%`.

**4. 결과 판정**
손익 > 0 → "익절", < 0 → "손절", 0 근처 → "본절".

**5. 손절 준수 확인**
`손절액` > 0 이고 손실인데 `|손익| > 손절액 × 1.1` 이면
`실수 태그`에 "손절 늦음"을 추가하고 한 줄로 알린다.

**6. 페이지 생성** (`mcp__Notion__notion-create-pages`)
- 날짜는 **반드시** `"date:날짜:start": "YYYY-MM-DD"` 확장 키로.
- 제목 예: `BTCUSDT 롱 — 7/22`
- 스크린샷은 `스크린샷` 속성에 첨부하거나 본문에.
- 본문 골격: `## 📍 진입 상황` / `## ✅ 잘한 점` / `## ⚠️ 실수·반성` / `## 🔧 다음 개선점`

**7. 반성 유도**
"잘한 점 / 실수 한 가지씩 적어볼까요?" → 답을 `반성일지`와 본문에.

**8. 확인**
페이지 URL과 자동 계산된 수익률(%)을 알려준다.

**9. 10회차마다**
> 이번이 N회차네요. 노션에서 CSV 내보내서
> `python -m dorothy journal <파일>` 돌리면 셋업별 기대값과 R 분석이 나옵니다.

## 셋업 이름

`지지저항` 수평 지지/저항 반응 · `되돌림` 추세 중 되돌림(피보나치 포함) ·
`돌파` 박스·채널·전고점 돌파 · `유동성스윕` 고점/저점 쓸고 되돌아온 자리 ·
`이평` 이동평균 크로스/지지 · `뉴스` 뉴스·이벤트 · `감` 근거 없음

새로 만들지 말고 재사용해야 통계가 쌓인다. 정말 없을 때만 새로 만들고
사용자에게 알려 다음부터 같은 이름을 쓰게 한다. `감`을 고르는 것도 데이터다.

## 속성

| 속성 | 타입 | 비고 |
|---|---|---|
| 제목 | title | 심볼+방향+날짜 |
| 날짜 | date | `date:날짜:start` 확장 키 |
| 심볼 | select | BTCUSDT/ETHUSDT/SOLUSDT/XRPUSDT/기타 |
| 방향 | select | 롱 / 숏 |
| 레버리지 | number | |
| 진입가 / 청산가 | number | |
| **진입 근거** | text | **필수. `[셋업이름] 설명`** |
| 시작금액 | number($) | 증거금 |
| 손익 | number($) | |
| **손절액** | number($) | **필수. 미설정이면 0 + "손절 미설정" 태그** |
| 수익률(%) | formula | 자동 — 입력 금지 |
| 결과 | select | 익절/손절/본절 |
| 실수 태그 | multi_select | 계획대로/뇌동매매/추격매수/손절 늦음/과도한 레버리지/분할 실패/FOMO/익절 조급/손절 미설정 |
| 반성일지 | text | |
| 스크린샷 | file | |

`수익률(%)`, `회차`는 자동이라 값을 넣지 않는다.
