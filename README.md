# KF로지스틱 — 고객별 미수금 안내 · 공지사항 자동 발송

엑셀 미수금 원장을 올리면 **안내 문구의 큰 틀은 그대로 두고**, 고객마다 다른 부분
(미수 내역, 합계, 건수, 납부기한, 연체일수, 담당자 등)을 자동으로 채워
**내 PC 카카오톡**, 카카오 알림톡, 문자 중 하나로 보내는 프로그램입니다. 나인톡처럼 엑셀 → 미리보기 → 발송 순서로 씁니다.

```
[KF로지스틱 미수금 안내]                        [KF로지스틱 미수금 안내]
안녕하세요, #{고객명}님.                          안녕하세요, 마닐라푸드님.
#{기준일} 기준 미수금 내역을 안내드립니다.   →    2026-10-06 기준 미수금 내역을 안내드립니다.
                                                - 2026-08-03 해상운임 인천→마닐라 2CBM 380,000원
#{미수내역}                                      - 2026-08-20 냉동창고 보관료(8월) 100,000원
                                                - 2026-09-15 통관 수수료 120,000원
■ 미수 합계: #{미수총액}원 (#{미수건수}건)          ■ 미수 합계: 600,000원 (3건)
```

## 메뉴

| 메뉴 | 하는 일 |
|---|---|
| **미수금 안내** | 원장 엑셀을 고객별로 묶어, 고객마다 미수 내역·합계가 들어간 안내를 보냅니다 (미수금 0원인 고객 제외) |
| **공지사항** | 명단의 모든 고객에게 같은 공지를 `#{고객명}`만 바꿔 보냅니다. 엑셀(미수금 원장도 가능)을 올리거나 이름을 직접 입력합니다 |
| **카톡 이름 정리** | 내 PC 카카오톡 친구/채팅 목록의 이름을 읽어 와서 엑셀 고객명과 자동으로 짝을 맞추고, `카톡이름` 열을 채운 엑셀을 만들어 줍니다 |

문구는 `templates/미수금/`, `templates/공지/`에 따로 저장됩니다. 화면 2번에서 문구를 관리할 수 있습니다.

- **➕ 새 이름으로 저장**: 지금 편집칸의 문구를 새 이름으로 추가합니다. 저장하면 목록에서 바로 선택됩니다.
- **💾 덮어쓰기 저장**: 고른 문구를 고친 내용으로 바꿉니다. 고친 뒤 저장하지 않았으면 "아직 저장되지 않았습니다"가 표시됩니다.
- **🗑️ 이 문구 삭제**: 한 번 더 확인한 뒤 지웁니다.
- **➕ 새 문구 (빈 칸에서 시작)**: 목록 맨 아래에서 고르면 빈 칸에서 새로 씁니다.
- 프로그램을 새 버전으로 덮어쓸 때 기본 문구(01_…, 02_… 등)는 원래 내용으로 돌아갈 수 있습니다. 자주 쓰는 문구는 **새 이름으로 저장**해 두세요. 휴무 안내와 가격 변경 공지 예시가 들어 있습니다.
같은 날 같은 종류(미수금 또는 공지)를 이미 보낸 고객은 기본으로 빠지고, 미수금 안내를 보낸 날에도 공지는 따로 보낼 수 있습니다.

## 📎 사진·파일 함께 보내기 (PC 카카오톡 전용)

문구를 보낸 뒤 사진이나 파일을 이어서 보냅니다. 미수금 안내와 공지사항 모두 됩니다.

- **모두에게 같은 첨부**: 2번 문구 아래 '함께 보낼 사진·파일'에 올립니다. 여러 개를 올릴 수 있고, 예를 들면 공지 이미지나 가격표 PDF입니다.
- **고객마다 다른 첨부**: 엑셀에 `첨부파일` 열을 만들고 파일 경로를 적습니다. 예) `C:\명세서\마닐라푸드.pdf`. 여러 개면 `;`로 구분합니다.
  같은 고객의 여러 줄에 같은 경로를 적거나, 한 줄에만 적으세요. 고객마다 값이 하나여야 합니다.
- 경로의 파일이 없으면 그 고객은 '확인 필요'로 표시되고 보내지 않습니다.
- 첨부를 보낼 때는 채팅방 창이 맨 앞으로 나오고 붙여넣기(Ctrl+V)와 Enter가 자동으로 눌립니다. **발송이 끝날 때까지 키보드·마우스를 건드리지 마세요.**
- 글은 갔는데 첨부만 실패하면 '성공'으로 기록되고(같은 글이 두 번 가지 않도록) 상세에 `⚠️ 첨부 실패`가 표시됩니다. 그 고객에게는 파일만 따로 보내 주세요.
- 문구를 비워 두면 파일만 보냅니다.

## ⏰ 예약 발송

화면 맨 아래 **5. 예약 발송**에서 지금 화면의 설정(문구, 열 지정, 발송 방식, 첨부, 테스트 모드)을 저장해 두면, 정해진 시간에 Windows 작업 스케줄러가 자동으로 보냅니다.

- 반복: **한 번 / 매일 / 매주(요일) / 매월(며칠)**
- 엑셀: **지금 올린 엑셀을 저장**해서 쓰거나, **경로를 지정**해 예약 시간에 다시 읽을 수 있습니다(매번 최신 원장). 반복 예약이면 원장을 늘 같은 위치에 덮어써 두고 경로 방식을 고르세요.
- 예약 발송은 3번 표의 체크와 관계없이, 예약 시간에 **보낼 수 있는 모든 고객**에게 보냅니다. 문제가 있거나 그날 이미 보낸 고객은 빠집니다.
- 테스트 모드를 켠 채로 예약하면 예약도 '나에게 N건'으로 갑니다. **처음에는 몇 분 뒤 테스트 예약**으로 확인해 보세요.
- 예약 시간에는 **PC가 켜져 있고 로그인(화면 잠금 해제) 상태**여야 합니다. PC 카카오톡도 로그인돼 있어야 합니다. 브라우저 화면은 꺼져 있어도 됩니다.
- 예약 시간에 검은 창이 열려 진행 상황을 보여 주고, 끝나면 30초 뒤 닫힙니다. 결과는 예약 목록의 **실행 기록**에서 볼 수 있습니다.
- 예약 목록에서 다음 실행 시각 확인과 삭제를 할 수 있습니다. 예약은 Windows 작업 스케줄러의 `KFLogistics` 폴더에도 보입니다.
- 알림톡·문자 예약은 `.env` 파일의 솔라피 키를 씁니다.

## 🧪 테스트 모드

실제 발송 방식(PC 카카오톡, 알림톡, 문자)을 고르면 **테스트 모드가 기본으로 켜져 있습니다.**

- 선택한 고객들의 메시지를 **고객이 아니라 '나'(입력한 카톡 이름이나 휴대폰 번호)에게** 보냅니다.
- 메시지 맨 위에 `[테스트 · 원래 받는 사람: 마닐라푸드]`처럼 원래 받을 고객 이름이 붙습니다.
- 몇 건만 보낼지 정할 수 있습니다(기본 3건).
- 테스트로 보낸 건은 '오늘 이미 보냄'으로 치지 않으므로 실제 발송에 영향이 없습니다. 다만 PC 카카오톡 하루 한도에는 포함됩니다.
- 받은 메시지가 괜찮으면 테스트 모드를 끄고, 확인 체크를 한 뒤 실제로 발송합니다.

## 카톡 이름 정리

1. PC 카카오톡을 켜고 메인 창에서 **채팅** 탭(또는 **친구** 탭)을 눌러 둡니다.
2. 메뉴에서 **카톡 이름 정리**를 고르고 **🎯 정확하게 읽기**를 켠 채(기본값) **PC 카카오톡에서 이름 읽어 오기**를 누릅니다.
   - 나인톡처럼 목록 첫 방을 선택하고 **Enter로 열기 → 창 제목에서 정확한 이름 읽기 → 닫기 → ↓ 다음 방**을 목록 끝까지 반복합니다.
   - 글자 인식을 쓰지 않아 이름이 정확하고, 한국어 글자 인식 설치도 필요 없습니다.
   - 방 하나에 1~2초 걸리고, 방을 열기 때문에 **안 읽은 메시지가 '읽음' 처리**됩니다.
   - 키보드·마우스가 자동으로 움직이니 **끝날 때까지 건드리지 마세요.**
   - 정확하게 읽기를 끄면 화면 글자 인식(OCR)으로 빠르게 읽습니다. 방을 열지 않는 대신 글자가 틀릴 수 있습니다(채팅→재팅 등).
3. 읽어 온 이름 표에서 필요 없는 줄은 지우고, 틀린 글자는 고칩니다.
4. 고객 엑셀을 올리면 고객명마다 가장 비슷한 이름을 찾아 줍니다. 띄어쓰기, 괄호, '사장님·대표님' 같은 호칭은 무시하고 비교합니다.
   채팅 목록에서 읽었으면 결과는 `채팅방` 열에 저장되어 그 고객들은 채팅방으로 보내집니다.
5. **열을 채운 엑셀 받기**를 눌러 저장하고, 그 엑셀을 발송에 그대로 씁니다.

## 설치와 실행

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # 솔라피 키, 발신번호, 발신프로필 ID 입력
streamlit run app.py               # 브라우저에서 화면이 열립니다
```

Windows에서는 `실행.bat`을 더블클릭하면 됩니다.
새 버전이 나오면 **`업데이트.bat`을 더블클릭**하세요. 최신 버전을 받아 이 폴더에 덮어쓰고(설치된 프로그램·발송 이력·첨부는 그대로), 프로그램을 다시 켜서 브라우저까지 열어 줍니다. 처음 한 번은 설치 때문에 몇 분 걸립니다.

처음에는 **샘플 데이터 + '미리보기' 모드**로 실제 발송 없이 동작을 확인해 보세요.

## 엑셀 형식

거래 1건이 엑셀 1줄이면 됩니다. 같은 고객(고객명+전화번호)의 여러 줄은 자동으로 묶입니다.
샘플: `samples/미수금_샘플.xlsx`

| 고객명 | 전화번호 | 거래일자 | 품목 | 미수금 | 납부기한 | 담당자 | 입금계좌 |
|---|---|---|---|---|---|---|---|
| 마닐라푸드 | 010-1234-5678 | 2026-08-03 | 해상운임 2CBM | 380000 | 2026-09-10 | 김담당 | 국민 … |

- 열 이름이 달라도 화면에서 고객명, 전화번호, 미수금액, 납부기한 열을 직접 지정할 수 있습니다.
- 미수금이 0원 이하인 고객(완납 고객)은 자동으로 빠집니다.
- 전화번호 형식이 틀린 고객이나 값이 비어 있는 변수가 있는 고객은 '확인 필요'로 표시되고 발송되지 않습니다.
- 같은 날 이미 발송에 성공한 고객은 기본으로 제외됩니다(중복 발송 방지). 이력은 `logs/send_log.csv`에 남습니다.

## 템플릿 변수

| 변수 | 내용 |
|---|---|
| `#{고객명}` `#{전화번호}` | 고객 정보 |
| `#{미수총액}` `#{미수건수}` | 고객별 합계와 건수 (금액은 자동으로 콤마 표시) |
| `#{미수내역}` | 미수 건마다 한 줄씩 만든 목록. 한 줄 서식은 화면에서 바꿀 수 있습니다 (기본 `- #{거래일자} #{품목} #{미수금}원`) |
| `#{기준일}` | 오늘 날짜 |
| `#{최초납부기한}` `#{연체일수}` | 납부기한 열을 지정했을 때, 가장 빠른 기한과 그 기한부터 지난 일수 |
| `#{엑셀열이름}` | 고객 안에서 값이 하나뿐인 열(담당자, 입금계좌 등)은 열 이름 그대로 사용할 수 있습니다 |

템플릿은 `templates/*.txt`에 저장되고, 화면에서 수정한 뒤 새 이름으로 저장할 수도 있습니다.

## PC 카카오톡으로 보내기 (카카오 채널 없이)

내 PC에 로그인된 카카오톡을 프로그램이 대신 조작해서, **내 계정으로** 거래처 채팅방에 메시지를 보냅니다.
카카오 채널, 솔라피 가입, 비용 모두 필요 없습니다.

> ⚠️ 카카오 공식 기능이 아니라서 카카오 운영정책상 **계정이 제한되거나 정지될 수 있습니다.**
> 거래처에 보내는 소량의 안내 용도로만 쓰시고, 간격을 넉넉히 두고 하루 발송 수를 적게 유지하세요.

1. **Windows PC**에서 PC 카카오톡을 켜고 로그인합니다. 창은 최소화해도 되지만 닫거나 로그아웃하면 안 됩니다.
2. `실행.bat`으로 프로그램을 켜고, 왼쪽 발송 방식에서 **PC 카카오톡(내 계정)**을 고릅니다.
3. 받는 사람은 **카톡 친구 목록(또는 채팅 목록)에 보이는 이름**으로 찾습니다.
   - 카톡에 저장된 이름이 엑셀의 고객명과 다르면 엑셀에 `카톡이름` 열을 만들어 적어 주세요. 비어 있으면 고객명으로 찾습니다.
   - **채팅방(단톡방 포함)으로 보내려면** 엑셀에 `채팅방` 열을 만들어 채팅방 이름을 적으세요. 값이 있는 고객은 친구 대신 채팅 목록에서 그 채팅방을 찾아 보냅니다.
     찾는 순서는 ① `채팅방` → ② `카톡이름` → ③ 고객명 입니다. 미리보기 표에 👤(친구) / 💬(채팅방)로 표시됩니다.
   - 공지사항의 '이름 직접 입력'에서도 "채팅방 이름"을 고르면 입력한 이름을 채팅방으로 찾습니다.
   - 열린 채팅방의 **제목이 그 이름과 정확히 같을 때만** 보냅니다. 이름이 다르거나 비슷한 이름이 여러 개면 보내지 않고 '채팅방을 찾지 못함'으로 남기니, 엉뚱한 사람에게 가지 않습니다.
4. '테스트 메시지 1건 먼저 보내 보기'로 본인이나 지인에게 먼저 보내 보세요.
5. 안전장치
   - 메시지 사이에 무작위 간격을 둡니다(기본 8~15초).
   - 하루 최대 발송 수를 정할 수 있습니다(기본·최대 500건).
   - 연속 3건이 실패하면 발송을 멈춥니다.
   - 한 건 보낼 때마다 바로 이력에 기록하므로, 중간에 멈춰도 다시 실행했을 때 이미 보낸 고객에게 중복으로 가지 않습니다.

카카오톡이 업데이트되어 창 구조가 바뀌면 검색칸이나 입력칸을 못 찾을 수 있습니다.
그럴 때는 `receivables/kakao_pc.py` 맨 위의 창 클래스 이름만 고치면 됩니다.

## 실제 발송 준비 (카카오 알림톡)

1. 사업자 인증을 받은 **카카오톡 채널**을 만듭니다.
2. [솔라피](https://solapi.com)에 가입하고, 발신번호를 등록하고, 카카오 채널을 연동합니다. 연동하면 발신프로필 ID(pfId)를 받습니다.
3. 솔라피에서 **알림톡 템플릿을 등록하고 카카오 검수**를 받습니다. 검수에는 보통 1~3영업일이 걸립니다.
   - 이 프로그램의 템플릿 문구와 검수받은 문구는 **변수 이름까지 완전히 같아야** 합니다.
   - 미수금 안내는 정보성 메시지라 알림톡 용도에 맞습니다. 다만 광고 문구(할인, 이벤트 등)가 섞이면 반려됩니다.
4. `.env`에 API Key, Secret, 발신번호, pfId를 넣고, 화면에서 '카카오 알림톡'과 템플릿 ID를 선택해 발송합니다.

'알림톡 실패 시 문자로 대체'를 켜 두면 카카오톡을 쓰지 않는 고객에게는 문자로 보내집니다.
결과에 나오는 '접수 완료'는 솔라피가 요청을 받았다는 뜻입니다. 최종 도착 결과는 솔라피 콘솔에서 확인하세요.

## 자동 실행 (명령줄)

정해진 날마다 자동으로 보내려면 명령줄 버전을 Windows 작업 스케줄러나 cron에 등록하면 됩니다.

```bash
# 미리보기 (발송 안 함)
python cli.py 원장.xlsx templates/미수금/01_미수금_안내.txt
# 내 PC 카카오톡으로 발송 (Windows)
python cli.py 원장.xlsx templates/미수금/01_미수금_안내.txt --mode kakao-pc --gap 8 15 --daily-cap 500
# 공지사항 (명단 전원), 테스트 모드로 나에게 3건만
python cli.py 명단.xlsx templates/공지/02_휴무_안내.txt --kind 공지 --mode kakao-pc --test-to "내 카톡이름"
# 알림톡 실제 발송
python cli.py 원장.xlsx templates/미수금/01_미수금_안내.txt --mode alimtalk --template-id KA01TP...
```

## 개발

```bash
pytest
```

- `receivables/loader.py`: 엑셀 읽기, 고객별 묶기, 변수 만들기
- `receivables/template.py`: `#{변수}` 치환과 금액·날짜 서식
- `receivables/sender.py`: 솔라피 API(알림톡/문자)와 모의 발송
- `receivables/kakao_pc.py`: PC 카카오톡 조작 발송 (Windows, pywin32)
- `receivables/kakao_names.py`: 카톡 친구/채팅 이름 읽기(pywinauto)와 고객명 짝맞추기
- `receivables/campaign.py`: 메시지 준비, 검증, 발송, 이력 기록
- `receivables/runner.py`: 발송 작업 한 건 실행(명령줄·예약 공용)
- `receivables/scheduler.py`: 예약 저장, Windows 작업 스케줄러 등록
- `app.py`: Streamlit 화면 / `cli.py`: 명령줄 실행 / `run_schedule.py`: 예약 시간에 실행되는 파일
